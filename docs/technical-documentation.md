# Technical Documentation – Assignment 1

## Overview
This project is a responsive personal portfolio website built using HTML, CSS, and JavaScript.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (DOM manipulation, localStorage)
- Git & GitHub for version control

## File Structure
- `index.html`  
  Contains the page layout including the navigation bar, hero section, about, projects, and contact form.

- `css/styles.css`  
  Contains all styling including:
  - theme variables
  - layout using Grid/Flexbox
  - responsive media queries

- `js/script.js`  
  Contains interactive features:
  - Dark/Light theme toggle with localStorage saving
  - Greeting message based on time of day
  - Mobile menu toggle
  - Contact form submission demo message

## Responsive Design Approach
- The website uses CSS Grid for main section layouts.
- Media queries adjust layout below 900px and 700px.
- Projects and contact sections switch from multi-column to single-column on small screens.

## JavaScript Interactivity
The project includes:
1. Theme Toggle (dark/light)
2. Greeting message by time of day
3. Mobile navigation menu
4. Contact form interaction (demo)

## Testing
- Tested by resizing browser window and using DevTools mobile view.
- Confirmed that the site remains usable and readable on smaller screens.
