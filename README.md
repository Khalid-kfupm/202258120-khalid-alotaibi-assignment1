# Assignment 1 – Personal Portfolio Website

This project is a simple responsive personal portfolio website created for Assignment 1.  
It includes an About section, Projects section, and a Contact form, along with basic JavaScript interactivity.

## Features
- Responsive layout (desktop, tablet, mobile)
- About, Projects, and Contact sections
- Dark/Light mode toggle
- Greeting message based on time of day
- Contact form interaction (demo)

## Folder Structure
- `index.html` → Main page
- `css/styles.css` → Styling and responsive design
- `js/script.js` → Interactivity
- `assets/images/` → Images used in the site
- `docs/` → AI usage report and technical documentation

## How to Run Locally
1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser
